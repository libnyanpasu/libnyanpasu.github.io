---
title: "Add Icons to Proxy Groups"
---

This example adds the `icon` extension to matching proxy groups. Icon support depends on the selected core. See [Choose and manage a core](/tutorial/cores-and-compatibility) before applying it.

Uses icon sets from [Koolson/Qure](https://github.com/Koolson/Qure) and flag icons from [HatScripts/circle-flags](https://github.com/HatScripts/circle-flags).
