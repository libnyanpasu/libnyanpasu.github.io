Clash Nyanpasu is a cross-platform desktop client built with Tauri for managing Clash-compatible proxy profiles and their runtime on Windows, macOS, and Linux. The 2.0 release line adds a redesigned profile workflow, traffic analysis, and a customizable dashboard.

## What you can do

- Import remote subscriptions and local configuration files, then choose which profile is active.
- Add YAML, JavaScript, or Lua transformations to a profile and inspect generated configuration changes.
- Choose proxy nodes, view delay results, and inspect connections, rules, logs, and traffic reports.
- Arrange dashboard widgets for traffic, connections, proxy status, core status, and subscription information.

Feature availability can depend on the selected core, operating system, and release package. See the [installation guide](./tutorial/install) and the [current releases](https://github.com/libnyanpasu/clash-nyanpasu/releases) for platform details.

## Platform and core support

<Badge text="Windows" variant="success" /> <Badge text="macOS" variant="success" /> <Badge text="Linux" variant="success" />

The app includes several core engines, each with different configuration support. The current built-in choices are Clash Premium, Mihomo and Mihomo Alpha, Clash Rust and Clash Rust Alpha, and Meow and Meow Alpha. Check [core compatibility](./tutorial/cores-and-compatibility) before selecting an engine for a profile.

## Features

- Choose proxy nodes and change routing modes from the tray menu.
- Manage and update multiple stable and Alpha core builds in the app.
- Apply profile transformations with YAML, JavaScript, or Lua, and manage remote providers.
- Use the Material You interface and its motion effects across the main views.
- Configure mixed proxy ports, including automatic selection of a free port.
- Review connections, rules, logs, subscriptions, and traffic from one desktop app.

## The name and icon

The name _Nyanpasu_ comes from Nyanpasu AOSP. The project initially adopted its icon and received permission from its owners to use the name and logo. The project also acknowledges the open-source community and the projects that make its core engines and desktop app possible.

In Chinese, _喵帕斯 (Miāo pà sī)_ is a convenient abbreviation for Clash Nyanpasu.

The project is free and open source. Contributions and issue reports are welcome on [GitHub](https://github.com/libnyanpasu/clash-nyanpasu).
