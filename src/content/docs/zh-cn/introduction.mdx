## 可以用它做什么

- 导入远程订阅和本地配置文件，并选择当前启用的配置。
- 为配置添加 YAML、JavaScript 或 Lua 转换，并检查生成配置的变化。
- 选择代理节点、查看延迟结果，以及检查连接、规则、日志和流量报告。
- 将流量、连接、代理状态、内核状态和订阅信息等小组件排列到仪表盘。

具体功能可能受所选内核、操作系统和安装包影响。平台信息请参阅[安装指南](./tutorial/install)和 [GitHub 当前发布版本](https://github.com/libnyanpasu/clash-nyanpasu/releases)。

## 平台与内核支持

<Badge text="Linux" variant="success" />

应用内置多个代理内核，各自支持的配置字段和功能有所不同。当前可选内核包括 Clash Premium、Mihomo 与 Mihomo Alpha、Clash Rust 与 Clash Rust Alpha，以及 Meow 与 Meow Alpha。选择内核前，请先阅读[内核兼容性说明](./tutorial/cores-and-compatibility)。

## 功能

- 从托盘菜单选择代理节点并切换路由模式。
- 在应用内管理和更新多个 Stable 与 Alpha 内核版本。
- 使用 YAML、JavaScript 或 Lua 转换配置，并管理远程提供者。
- 使用采用 Material You 设计的界面和动效。
- 配置混合代理端口，也可以自动选择可用端口。
- 在同一桌面应用中查看连接、规则、日志、订阅和流量。

## 名称与图标

名称中的 _Nyanpasu_ 来自 Nyanpasu AOSP。项目早期沿用了 Nyanpasu AOSP 的图标，并获得其所有者授权使用名称和标志。项目也感谢开源社区，以及为内核和桌面应用提供基础的各个项目。

中文交流中也常用 _喵帕斯_ 作为 Clash Nyanpasu 的简称。

本项目是自由开源软件，欢迎通过 [GitHub](https://github.com/libnyanpasu/clash-nyanpasu) 参与贡献或反馈问题。
