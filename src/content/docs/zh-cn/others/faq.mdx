## 应用

### macOS 提示“Clash Nyanpasu 已损坏，无法打开”

请先确认应用来自[官方发布页](https://github.com/libnyanpasu/clash-nyanpasu/releases)，然后重新下载安装包，以排除下载不完整的情况。“已损坏”提示可能并非清除隔离属性就能解决；旧版 `xattr` 指令不是通用修复方法。如果问题仍然存在，请在[GitHub 问题](https://github.com/libnyanpasu/clash-nyanpasu/issues/new/choose)中提供具体的 macOS 和应用版本。

如果提示无法确认开发者，请先尝试打开应用，再前往**系统设置 → 隐私与安全性**，对该应用选择**仍要打开**。具体步骤请参阅 [Apple 的说明](https://support.apple.com/en-ie/102445)。

### 配置目录和日志目录在哪里？

打开**设置**，使用配置目录或数据目录旁的文件夹按钮。托盘菜单也有打开目录的快捷入口。日志保存在数据目录下的 `logs` 文件夹。若应用无法打开，可在文件管理器中输入下面对应系统的路径。

#### 默认目录路径

- Windows：配置目录为 `%APPDATA%/Clash Nyanpasu/config`，数据目录为 `%LOCALAPPDATA%/Clash Nyanpasu/data`。
- macOS：`~/Library/Application Support/Clash Nyanpasu`。
- Linux：配置目录为 `$XDG_CONFIG_HOME/clash-nyanpasu` 或 `$HOME/.config/clash-nyanpasu`；数据目录为 `$XDG_DATA_HOME/clash-nyanpasu` 或 `$HOME/.local/share/clash-nyanpasu`。

从 v1.6.0 开始，配置和数据分别存放，日志目录位于数据目录内。Windows 用户可以自定义或迁移配置目录。若设置了自定义目录，以自定义路径为准。

Windows 便携版会将配置目录和数据目录放在可执行文件旁的 `.config/clash-nyanpasu` 与 `.data/clash-nyanpasu`。不同安装包的说明请参阅[安装指南](../../tutorial/install)。

### 如何修改应用日志等级？

打开**设置 → Nyanpasu 设置**，修改**应用程序日志级别**，保存后立即生效。可选等级为 `trace`、`debug`、`info`、`warn`、`error` 和 `silent`（不输出应用日志）。

旧版指南中直接修改 `nyanpasu-config.yaml` 的方法针对的是旧设置文件；当前版本请在设置中修改日志级别。

### 如何开启 TUN？

请参阅[系统代理与 TUN](../../tutorial/system-proxy-tun)。操作步骤取决于操作系统和安装包。不要把 1.x 的手动权限命令用于 2.0 安装。

### 为什么订阅没有返回可用节点？

部分服务商会根据请求的 User-Agent 决定返回内容。Clash Nyanpasu 默认发送 `clash-nyanpasu/v{version}`，其中 `{version}` 是应用版本。请询问服务商是否支持此值，或将配置的**用户代理**改成服务商认可的值，例如 `clash-meta`。添加订阅时可以设置，也可以在配置的更新选项中修改。不要在公开问题中分享完整订阅链接。

### 应用目录和内核目录是什么？

应用目录（内核目录）包含应用自带的资源和内核文件，可从托盘菜单或**设置**打开。请通过**设置 → 系统服务**安装和管理系统服务，不要手动安装服务二进制文件。大多数用户不需要直接修改应用目录中的文件。

## 使用应用

### 应该选择哪种模式？

建议先使用[系统代理和规则模式](../../tutorial/system-proxy-tun)。如果需要接管不遵循操作系统代理设置的应用，可以考虑 TUN，并先了解对应的平台权限要求。

### 如何选择或更新内核？

打开**设置 → Clash 设置**，使用**核心管理**。可选内核和兼容性说明请参阅[选择和管理内核](../../tutorial/cores-and-compatibility)。

### 应该从哪里开始？

先查看[配置与订阅](../../tutorial/profiles-and-subscriptions)导入或更新配置，再阅读[仪表盘与流量分析](../../tutorial/dashboard-and-traffic)了解运行数据。
