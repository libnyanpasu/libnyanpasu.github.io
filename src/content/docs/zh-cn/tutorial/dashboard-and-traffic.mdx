仪表盘展示可配置的运行概况；流量分析帮助你了解流量来自哪里、由哪个进程产生，以及经过了怎样的路由。 <Badge text="需要已收集的流量" variant="note" />

```mermaid
flowchart LR
    A[运行中的内核] --> B[已收集的连接]
    B --> C[时间范围与连接范围]
    C --> D[进程、入站、主机、出口与路由视图]
    D --> E[检查连接或规则]
```

## 调整仪表盘小组件

1. 在主导航中打开**概览**。
2. 在概览操作或右键菜单中选择**编辑小组件**。
3. 打开**添加小组件**，添加希望常驻显示的信息。
4. 编辑时可以拖动小组件调整位置，并在网格允许时调整大小。
5. 布局完成后退出编辑状态。

可用组件包括流量统计、活动连接、内存、代理和内核快捷操作、订阅用量，以及按来源、入站、目标、出口或规则汇总的近期流量。部分组件需要内核正在运行，并且已有近期流量数据。

## 查找流量来源或目标

1. 在主导航中打开**流量**。
2. 从总览开始，再选择**热门进程**、**热门入站**、**热门主机**、**热门出口**或**热门设备**。
3. 选择一项以聚焦报告；打开**连接路径**查看流量经过的阶段，或打开**地理分布**查看位置汇总。
4. 如果要调查某条连接，继续查看**连接**或**规则**，核对目标地址、命中的规则和代理路由。

流量报告依赖正在运行的内核收集的数据，也会受时间范围、连接范围和筛选条件影响。报告会按分钟或小时聚合流量；滑动时间范围可能包含边界所在的时间桶，因此不一定精确到某一时刻。配置归属在首次观察连接时记录；切换配置后仍保持打开的连接会保留原来的归属。数据保留设置也会限制报告可查询的历史范围。

## 筛选报告

使用**范围**显示全部、活跃或已结束的连接。选择按**流量**还是**连接数**排名，再选择时间范围：1 小时、6 小时、24 小时、7 天、30 天，或全部保留数据。如果保留时间不够长，相应范围可能不可用。

<Aside type="caution" title="缩短保留时间会删除旧记录">
  在**设置 → Nyanpasu 设置**中缩短**流量记录保留期限**后，超出新期限的旧记录会立即删除，且无法恢复。流量记录包含访问过的主机名。
</Aside>

<Aside type="note" title="地理分布是估算结果">
  地理分布优先使用连接实际拨号的地址，也可能使用本地 DNS 解析结果。代理可能使用不同的解析结果，且不会对代理出口进行地理定位。地图上的路线是区域之间的示意连接，并非实际测量的网络路径；页面最多绘制 32 条路线。
</Aside>

实时连接检查请参阅[完成首次连接](./first-connection)；要更换当前配置，请参阅[配置与订阅](./profiles-and-subscriptions)。
