Clash Nyanpasu 用于管理 Clash 兼容代理配置，并内置多个代理内核。请确认所选内核支持配置中使用的字段和功能；你还需要自行准备可用配置和代理。

<Badge text="新手指南" variant="tip" /> <Badge text="系统代理" variant="note" />

```mermaid
flowchart LR
    A[导入配置] --> B[启用配置]
    B --> C[选择代理节点]
    C --> D[选择规则或全局模式]
    D --> E[启用系统代理]
    E --> F[在连接页验证]
```

## 开始之前

- [安装 Clash Nyanpasu](../install) 并打开应用。
- 确保电脑已连接互联网。
- 从代理服务提供商处获取订阅链接，或准备一个包含至少一个代理的本地 Clash 兼容 YAML 配置（`.yaml` 或 `.yml`）。

不确定配置适用于哪个内核时，请先阅读[选择和管理内核](../cores-and-compatibility)，再导入配置。

## 1. 导入配置

在主导航中打开 **配置**，然后进入代理配置列表。

- **订阅链接：** 将订阅链接粘贴到页面顶部的快速导入框，然后点击下载按钮。
- **本地配置：** 点击右下角的 **导入配置**，选择 **本地**，保留 **单个配置**，选择 `.yaml` 或 `.yml` 文件，然后点击 **提交**。

等待新配置出现在列表中。订阅链接应由你的服务提供商提供；账户登录页面或单条代理链接不是订阅链接。

## 2. 启用配置

在配置卡片上点击 **启用配置**。启用后，卡片会高亮显示，启用按钮也会消失。应用会将该配置应用到正在运行的内核。

## 3. 选择并测试代理

打开 **代理**，选择配置规则使用的代理组，然后点击一个代理节点来选中它。有些代理组会自动选择节点，不支持手动选择；需要时请使用支持手动选择节点的代理组。

点击节点上的闪电按钮进行延迟测试。等待测试结果，然后选择一个有响应的节点。测试会使用配置中的延迟测试网址检查节点，并不能证明所有目标流量都会经过该节点。

如果路由模式为 **直连模式**，请从应用的设置菜单打开 **代理设置**，切换到 **规则模式** 或 **全局模式**。直连模式下流量不会使用代理出站。

## 4. 启用系统代理

打开 **设置 > 系统设置**，点击 **系统代理**。也可以在应用设置菜单的 **代理设置** 中切换 **系统代理**。确认该控件显示系统代理已启用。

系统代理会设置操作系统的代理选项，适用于遵循这些选项的应用；部分应用需要重启，也有些应用不会遵循系统设置。详情或 TUN 替代方案请参阅[系统代理与 TUN](../system-proxy-tun)。

## 5. 验证连接

打开遵循系统代理设置的浏览器或其他应用，访问一个会由当前配置通过代理转发的目标。在应用的 **连接** 页面找到这条请求，确认代理链中包含你选择的代理组或节点。规则模式下，部分目标可能会直连，因此除了确认网页能打开，也要检查连接的代理链。
