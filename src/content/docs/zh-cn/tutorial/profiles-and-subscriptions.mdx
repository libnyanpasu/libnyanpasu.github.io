配置文件为 Clash Nyanpasu 提供要交给所选内核处理的 Clash 兼容配置。应用原生支持多个内核，不同内核支持的字段和扩展可能不同。

## 选择配置来源 <Badge text="3 种来源" variant="note" />

<Tabs>
<TabItem label="远程">

代理服务提供商给出订阅 URL 时，选择远程配置。Clash Nyanpasu 会下载并保存配置，支持手动或定时更新。服务商也可能返回用量和到期信息。

导入表单还提供可选的 User-Agent、连接和更新间隔设置。间隔留空时会优先使用服务商建议值；没有建议值时，应用默认间隔为 120 分钟。

</TabItem>
<TabItem label="本地">

你已有 `.yaml` 或 `.yml` 配置文件时，选择本地配置。导入后，应用会将文件内容复制到应用管理的配置文件中；之后修改原文件不会自动同步。

</TabItem>
<TabItem label="链接文件">

当源文件由其他应用或编辑器管理，而你希望 Nyanpasu 跟随该文件时，选择链接文件。选择**镜像**会在应用侧保存副本，并随源文件变化同步；选择**符号链接**则直接引用源文件路径。

:::caution[链接文件要求]
请将源文件放在稳定且可读取的绝对路径下。Windows 创建符号链接需要启用开发者模式或使用管理员权限。如果源文件被移动或无法读取，配置将无法加载。
:::

</TabItem>
</Tabs>

:::caution[订阅链接隐私]
订阅 URL 可能包含账户凭据。不要在截图、公开问题、共享示例或日志中贴出完整 URL。如果链接泄露，请咨询服务商如何更换。
:::

如果你还没有配置或订阅，请联系代理服务商；Clash Nyanpasu 不提供代理订阅。

## 导入配置

<Steps>

1. 打开**配置**，在侧边栏选择**配置文件**。
2. 点击**新建配置**，然后选择**单个配置**。
3. 选择**远程**、**本地**或**链接文件**，并按上文说明填写 URL 或文件路径。
4. 设置名称和可选的更新间隔，然后点击**提交**。
5. 选择新配置；如果它尚未启用，请点击**启用配置**。

</Steps>

完整的首次使用流程请参阅[完成首次连接](./first-connection)。

## 更新订阅 <Badge text="仅远程配置" variant="tip" />

<Steps>

1. 打开远程配置的详情，点击**更新**以从当前 URL 获取配置。
2. 点击**更新选项**，启用或关闭**自动更新**，并设置分钟数间隔。
3. 刷新后检查配置的**更新时间**。设定间隔只代表更新计划，不代表更新成功。

</Steps>

在更新选项中将间隔留空时，应用默认使用 120 分钟。修改订阅 URL 并保存后，应用会立即从新地址下载配置。更新配置不会续费或延长服务商提供的订阅期限。

更新失败时，请检查 URL 是否仍有效、服务商是否允许此应用发起请求，以及 User-Agent 或连接选项是否符合服务商要求。寻求帮助时不要公开订阅 URL；[故障排查指南](./troubleshooting)说明了适合分享的信息。

## 配置与转换

配置文件是输入；应用生成运行时配置时，转换会对输入进行修改。将个人转换与服务商的远程配置分开，便于检查订阅更新的影响。2.0 的流程和检查工具请参阅[配置转换](./proxy-chain)。

切换内核后，请检查配置和转换中的字段是否受新内核支持。一个内核接受的字段，在另一个内核中可能不受支持或行为不同；详见[选择和管理内核](./cores-and-compatibility)。

如果内核已启动但流量没有使用预期配置，请先确认当前启用的是哪份配置，再检查代理组和[代理模式](./system-proxy-tun)。
